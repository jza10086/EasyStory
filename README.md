# StoryFlow（剧流）- 本地开源可视化游戏分支剧情工坊

专为独立游戏制作人、游戏策划、互动小说创作者打造的**本地、开源、极简抗 Bug**的可视化分支剧情编辑系统。

---

## 快速启动

在 Windows 资源管理器中：
- **双击 `start.bat`** 即可一键启动并在浏览器自动打开 `http://localhost:5173`。

或者在命令行运行：
```bash
npm run dev
```

---

## 核心功能一览

### 1. 节点式可视化画布（类似草图设计）
- **多分支结构**：支持主干剧情到各分支节点（如 `1` -> `1.1`、`1.2`、`1.3`）的拖拽构建。
- **分支条件即时标注**：连线上的标签直接显示触发条件（如 `[好感度 >= 60]`、`[持有钥匙]`），点击即可在连线上直接改写。
- **一键自动排版**：画布左下角自带“自动排版”按钮，节点再多也能一键整理得井井有条。

### 2. 节点详情抽屉（点击任意节点展开）
- **剧情正文与对白**：支持 Markdown 格式，提供纯编辑与实时双栏渲染模式。
- **本地插图上传**：一键上传立绘或场景图，自动保存到本地磁盘 `data/images/`，绝无 Base64 内存泄漏风险。
- **登场角色勾选**：勾选本节点参与的角色，自动关联人物性格与羁绊数值。
- **结局判定标记**：支持将节点标注为普通结局、真结局（True End）、坏结局（Bad End）。

### 3. 数据安全与抗 Bug 机制
- **磁盘实时自动防抖落盘**：所有修改在 800ms 内自动持久化写入本地 `data/story_graph.json`。
- **历史快照自动备份**：系统自动轮转归档最近 20 次修改到 `data/backups/`，防止误删或意外关机。

### 4. 与 Antigravity 及 AI 的深度结合
- **方式一（对话共创）**：所有故事、人物与世界观都在 `data/` 目录下，你在当前 Antigravity 聊天窗口中直接告诉我：
  > “请读取我的人设和节点 1.2，帮我设计 3 个带有好感度条件的分支节点写进工程”
  
  我可以直接在后台修改文件，你按 F5 即可同步看到！
- **方式二（网页内嵌 AI）**：在顶部【⚙️ AI设置】填入你的 API Key（支持 DeepSeek / SiliconFlow / OpenAI 等），在抽屉中点击“推荐分支”、“剧情润色”即可一键扩写。

## 本地数据目录结构

```
f:\NovelProject\
├── data/
│   ├── story_graph.json       # 核心故事图谱数据（节点与分支连线）
│   ├── characters.json        # 角色设定库（姓名、性格、立绘、好感度）
│   ├── world_lore.md          # 世界观全局法则与大纲（Markdown）
│   ├── settings.json          # AI 接口配置
│   ├── images/                # 本地插图与角色头像存放目录
│   └── backups/               # 自动创建的快照备份
├── src/                       # 前端源码（可随时让我二次编辑改造）
├── server.js                  # 本地数据服务
├── start.bat                  # 一键启动脚本
└── package.json
```
